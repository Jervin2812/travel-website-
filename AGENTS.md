# AI Coding Instructions — Travel Booking Website

- This project is a frontend-only static website built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.
- Do not add React, Vue, Node.js, a backend, database, or build tooling unless explicitly requested.
- Keep pages in `pages/`, styles in `css/`, scripts in `js/`, and local images/logos in `assets/`.
- Reuse the existing header, footer, button styles, cards, form controls, spacing, and color tokens.
- Preserve the travel-booking brand style: clean, calm, premium, image-led, accessible, and easy to scan.
- Make every page responsive; check 430px mobile, tablet, and desktop widths.
- Use semantic HTML, accessible form labels, descriptive alt text, and keyboard-friendly interactions.
- Do not invent live availability, payment success, confirmed reservations, or real booking submission. The project is a frontend demo unless an actual service is connected.
- Do not remove existing features or rewrite unrelated sections without a clear reason.
- Keep JavaScript in separate files and avoid inline styles/scripts.
- Test navigation links, date validation, mobile menu, and form feedback after edits.
