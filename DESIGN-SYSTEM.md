# Wanderly Travel Website — Design System

## Stack
HTML5, CSS3, Bootstrap 5, vanilla JavaScript. No framework or backend.

## Visual direction
Modern travel brand; editorial photography, generous whitespace, rounded cards, calm colors, clear hierarchy.

## Colors
- Primary teal: `#0D7C86`
- Primary hover: `#09636B`
- Main text: `#172B2D`
- Muted text: `#6D7B7C`
- Borders: `#E4E9E8`
- Light surface: `#F4F8F7`
- White: `#FFFFFF`

## Typography
Use Inter when available, with system sans-serif fallbacks. Use bold, tightly tracked headings and readable body text.

## Layout and components
- Bootstrap responsive grid.
- Main content max width: about 1160px.
- Card radius: 20px; form/button radius: 10–999px depending on component.
- Use consistent section spacing and image aspect ratios.
- Use destination cards, package cards, booking summary panels, and accessible forms consistently.

## Responsive targets
- Mobile reference: 430px
- Tablet reference: 768px
- Desktop: 1200px and above
- Avoid horizontal overflow and keep mobile sections in a single column where appropriate.

## Product behavior
Search, booking and contact forms are front-end demonstrations only. Do not imply they connect to real inventory, payment, email, or reservation systems.
