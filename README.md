# Wanderly — Travel Booking Frontend Starter

A static travel booking website starter using HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Pages
- `index.html` — home
- `pages/destinations.html` — destinations
- `pages/packages.html` — tour packages
- `pages/package-details.html` — package details
- `pages/booking.html` — booking request demo
- `pages/contact.html` — contact form demo

## Run in VS Code
1. Extract the ZIP.
2. Open the `travel-booking-frontend` folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.

Bootstrap and demo photos use external URLs, so an internet connection is required for those assets.

## Important
This is frontend-only. Forms show demo feedback and do not save or send data. There is no live inventory, account system, backend, or payment processing.
